9/25 周五

抵达 + 圣淘沙日落

iFly -> Skyline Luge -> Wings of Time

  1. 12:30
    CZ353 抵达 / Arrive at SIN

    入境后直接去酒店放行李，别在机场停太久。

  2. 16:30
    前往圣淘沙 / To Sentosa

    赶预约和日落，这段建议打车到 Beach Station。

  3. 18:00
    iFly Singapore / 新加坡风洞飞行

    需要提前 check-in，若延误就挪到 9/29。

  4. 18:50
    Skyline Luge / 新加坡天际滑车

    把 Skyride 缆车留给日落时段。

  5. 20:40
    Wings of Time / 时光之翼

    看完后逛 Sentosa Sensoryscape / 圣淘沙感官小径。

携带物品

护照、充电宝、防晒霜、轻便包、相机或手机稳定器。

备注

优先级：天际滑车日落 > 圣淘沙夜景 > iFly。

9/26 周六

殖民建筑 + 滨海湾夜景

Civic District -> Merlion Park -> Gardens by the Bay

  1. 09:30
    Civic District / 市政区

    莱佛士酒店、赞美广场、圣安德烈座堂，适合干净建筑照。

  2. 13:30
    National Gallery / 新加坡国家美术馆

    室内降温，也能拍旧市政厅和最高法院建筑。

  3. 17:30
    Merlion Park / 鱼尾狮公园

    傍晚拍 Marina Bay Sands / 滨海湾金沙天际线。

  4. 19:45
    Garden Rhapsody / 花园狂想曲

    接 Gardens by the Bay Mid-Autumn Festival / 中秋节庆典。

拍照清单

广角镜头、墨镜、轻薄外套、补妆用品、备用电量。

备注

这天照片最多，午后安排室内点，避免一直暴晒。

9/27 周日

环球影城整日

USS -> VivoCity Sanrio Moonlit Garden

  1. 09:20
    到达门口 / Arrive at USS

    先拍环球球，开园后直接进热门项目队列。

  2. 10:00
    热门项目优先 / Rides First

    上午集中处理排队压力，午后再拍照和看室内项目。

  3. 18:30
    VivoCity / 怡丰城

    Sanrio Characters Moonlit Garden / Sanrio 月漫花园，吃饭后撤退。

游园装备

轻便包、雨衣、防晒霜、水、门票二维码、少量现金。

备注

按周末人流准备。WaterWorld / 未来水世界维护中。

9/28 周一

水上探险 + 金沙夜景

Adventure Cove -> Lau Pa Sat -> Spectra

  1. 10:00
    Adventure Cove / 水上探险乐园

    尽量开园入场，热门滑道先玩。

  2. 16:30
    返回市区 / Back to City

    换衣、补水，留出从圣淘沙到 CBD 的移动时间。

  3. 19:00
    Lau Pa Sat / 老巴刹沙爹街

    晚餐吃沙爹，之后步行到滨海湾。

  4. 21:00
    Spectra / 滨海湾金沙光影水舞秀

    用夜景结束水上乐园日。

携带物品

泳衣、游泳鞋、防晒霜、手机防水袋、小背包。

备注

遇雷暴改去 Singapore Oceanarium / 新加坡海洋生态馆。

9/29 周二

换酒店 + 自由购物

Frasers House -> Orchard / Bugis -> Kampong Gelam

  1. 10:30
    换酒店 / Hotel Transfer

    Roxy 退房后打车去 Frasers House 寄存行李。

  2. 13:00
    自由逛街 / Flexible Shopping

    Orchard Road / 乌节路 或 Bugis Junction / 武吉士广场二选一。

  3. 19:00
    Kampong Gelam / 甘榜格南

    步行逛 Haji Lane / 哈芝巷、Sultan Mosque / 苏丹回教堂。

自由选项

乌节路购物、Bugis 逛街、补 iFly、咖啡馆休息。

备注

如果 9/25 没赶上 iFly，可以补到这天下午。
